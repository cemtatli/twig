# Twig 1.0.0

First downloadable release of Twig, a macOS menu-bar app for managing Git worktrees across local repositories.

## Downloads

- **Twig-1.0.0-universal.dmg** — open the disk image and drag Twig to Applications.
- **Twig-1.0.0-universal.zip** — extract and move Twig.app to Applications.
- **SHA256SUMS.txt** — SHA-256 checksums for both downloads.

Both packages include **Apple Silicon (arm64) and Intel (x86_64)** binaries and require **macOS 14 or later**. No Swift toolchain is needed to run the downloaded app.

## Included

- Scan local repositories and create worktrees on new or existing branches.
- Apply per-repository environment rules, dependency installation and setup commands.
- Open the editor and terminal with the development server ready to start.
- Configure repository defaults and launch at login.
- Runs in the menu bar, without a Dock icon.

## Signing and first launch

This release is **ad-hoc signed, not Developer ID signed or notarized**. macOS may block the first launch because Apple cannot verify the developer. Only if you trust this repository and have verified the download, follow [Apple's instructions for opening an unnotarized app](https://support.apple.com/en-us/102445): attempt to open Twig, then use **System Settings → Privacy & Security → Open Anyway** if that option is available.

Do not disable Gatekeeper system-wide. Twig does not bundle your repositories, environment files or personal configuration.

## Verify the download

Download SHA256SUMS.txt into the same folder as the packages, then run:

```bash
shasum -a 256 -c SHA256SUMS.txt
```
